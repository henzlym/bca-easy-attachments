Download beautiful, high-quality stock photos from Unsplash directly into your WordPress editor. No account required.

== Description ==

Easy Attachments brings the power of Unsplash's extensive photo library directly into your WordPress block editor. Browse, search, and download professional-quality images without ever leaving your post or page editor.

= Key Features =

* **Seamless Integration**: Access millions of free photos directly from the WordPress block editor sidebar
* **Multiple Actions**: Insert images into posts, set as featured images, or download to your media library
* **Image Size Options**: Choose from 5 different image sizes (Raw, Full, Regular, Small, Thumbnail) to optimize for your needs
* **Smart Search**: Real-time search with debouncing for fast, efficient browsing
* **Pagination**: Browse through results with easy-to-use navigation controls
* **Download Tracking**: Visual indicators show which images you've already downloaded
* **Persistent Status**: Downloaded images remain marked across sessions
* **Photographer Attribution**: Automatic credit to photographers with user information displayed on each image
* **Optimized Performance**: Debounced search queries and efficient API usage

= How It Works =

1. Open any post or page in the WordPress block editor (Gutenberg)
2. Look for the "Easy Attachments" panel in the right sidebar
3. Search for images using keywords or browse curated photos
4. Click any action button to see image size options
5. Select your preferred size (Regular is recommended for most uses)
6. The image is automatically downloaded and ready to use

= Image Sizes =

* **Raw**: Original quality (largest file size)
* **Full**: ~6000px (high resolution)
* **Regular**: ~1080px (recommended - best balance of quality and file size)
* **Small**: ~400px (for thumbnails or small displays)
* **Thumb**: ~200px (for icon-sized images)

== Installation ==

= Automatic Installation =

1. Log in to your WordPress dashboard
2. Navigate to **Plugins → Add New**
3. Search for "Easy Attachments"
4. Click **Install Now**
5. Click **Activate** after installation completes

= Manual Installation =

1. Download the plugin ZIP file
2. Log in to your WordPress dashboard
3. Navigate to **Plugins → Add New → Upload Plugin**
4. Choose the downloaded ZIP file
5. Click **Install Now**
6. Click **Activate Plugin** after installation completes

= After Activation =

1. Create or edit any post or page in the block editor
2. Look for the **Easy Attachments** panel in the right sidebar
3. Start searching for and downloading images!

== Frequently Asked Questions ==

= Do I need an Unsplash account? =

No! The plugin works immediately after activation. No API keys or accounts required.

= Are the images really free? =

Yes! All images from Unsplash are free to use under the [Unsplash License](https://unsplash.com/license). You can use them for commercial and non-commercial purposes.

= Do I need to credit the photographers? =

While not required by the Unsplash License, it's always appreciated. The plugin displays photographer information on each image to make attribution easy.

= Which image size should I use? =

For most WordPress posts and pages, we recommend the **Regular** size (~1080px). It provides excellent quality while keeping file sizes manageable. Use **Full** or **Raw** only when you need maximum resolution.

= Does this work with the classic editor? =

No, Easy Attachments requires the WordPress block editor (Gutenberg). The classic editor is not supported.

= Can I use this on multiple sites? =

Yes! You can install and use Easy Attachments on as many WordPress sites as you want.

= Does it slow down my site? =

No. The plugin only loads in the block editor and uses efficient API calls with debouncing and pagination to ensure optimal performance.

= What happens to downloaded images? =

Images are downloaded to your WordPress media library and stored on your server, just like any uploaded file. They remain available even if you deactivate the plugin.
